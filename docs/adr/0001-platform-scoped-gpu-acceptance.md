# GPU 完整結案採三項獨立驗收，結論限定驗證平台

GL 路徑成立、實體 GPU 執行與效能收益是不同的主張，現有 WSLg 環境也尚未完成應用程式硬體驗收。2026-10-05 訪談決定：三項皆 PASS 才可完整結案，期間允許階段交付；任一目標平台完成驗收即可滿足平台要求，但其他未完成平台維持 PENDING，不能沿用其 PASS。這接受跨平台驗收未同步完成的限制，以保留可交付的範圍與可核對的結論，而非要求所有平台同時通過或僅憑 GL 功能完成就結案。

平台限定不免除已列為必測的畫面與生命週期操作；任何必測項未完成，完整 GL 驗收保持 PENDING，不能縮小必測清單而結案。
